Setup on a Rocky 9 system wasn't too tricky for this image server. I opted to use a virtual environment as there were a lot of dependencies for the server.

```
# Update server to have Python > 3.9 
dnf install python3.12

# Prepare environment
mkdir ~/flux2-server && cd ~/flux2-server
python3.12 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install git+https://github.com/huggingface/diffusers.git transformers accelerate safetensors fastapi uvicorn pillow

# Launch server
python server.py
```

An image can be generated by POST-ing to port 6006 on the server, something like:
```
curl -X POST http://SERVER_IP:6006/generate \
  -H "Content-Type: application/json" \
  -d '{"prompt": "a mascot for an HPC environment. The mascot is cool/stylish, a rat and loves Infiniband", "seed": 42}' \
  --output mascot.png
```
